# Native build and release guide

The native applications are deliberately thin companions. The complete member experience remains the PWA; the companions pair to a signed-in member and synchronize Apple Health or Health Connect records through the existing `/api/native/register` and `/api/native/sync` endpoints.

## Continuous integration outputs

| Workflow | Output | Signing |
|---|---|---|
| `Web CI` | Cloudflare/Sites worker in `dist/` | Not applicable |
| `Native CI / Android` | Debug `.apk` and `.aab` | Android debug key generated by CI |
| `Native CI / iOS` | Zipped simulator `.app` | No signing; simulator only |
| `Signed Native Release` | Release `.apk`, `.aab`, `.ipa`, R8 mapping and dSYMs | Google Play upload key and Apple distribution profile |

## Android local build

Requirements: Android Studio with Android SDK 36, JDK 17, and Gradle 8.11.1.

```bash
cd native/android
MEMBER_OS_BASE_URL=https://app.antiaging-labs.com gradle :app:assembleDebug :app:bundleDebug
```

Artifacts are written under `app/build/outputs/apk/` and `app/build/outputs/bundle/`. The release build reads `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, `APP_VERSION`, and `ANDROID_VERSION_CODE` from the environment. Secrets are never committed.

The application requests each Health Connect category at runtime, stores its installation token using an Android Keystore AES-GCM key, keeps provider/source metadata, and schedules a network-constrained reconciliation every 12 hours after pairing.

## iOS local build

Requirements: Xcode 16 or newer, XcodeGen, an Apple Developer team, an App ID with HealthKit enabled, and a physical iPhone for HealthKit validation.

```bash
brew install xcodegen
xcodegen generate --spec native/ios/project.yml --project native/ios
open native/ios/AntiagingCompanion.xcodeproj
```

Select the developer team and a HealthKit-capable provisioning profile in Xcode. The project uses anchored HealthKit queries, saves an anchor only after a server batch succeeds, registers hourly observer delivery, and stores the installation token in a device-only Keychain item.

For a command-line simulator build:

```bash
xcodebuild -project native/ios/AntiagingCompanion.xcodeproj -scheme AntiagingCompanion -sdk iphonesimulator -derivedDataPath native/ios/DerivedData CODE_SIGNING_ALLOWED=NO build
```

For an App Store archive, use the **Signed Native Release** workflow. The repository contains the XcodeGen specification, complete Info.plist, HealthKit entitlements, privacy manifest, and export-options template. Final icons, screenshots, localized store copy, privacy labels, and account approvals are release inputs—not source-code build blockers.
